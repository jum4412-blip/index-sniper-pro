# 400 USDT × 5배 전략 추가 검증 (2026-10-01)

**결과: 실매매 승격 후보 없음.** 거래량을 강제로 늘리거나 음수 기대값을 양수라고 판정하지 않았습니다. 실거래, Bitget 전용 과거 체결, 실제 텔레그램 전송은 수행하지 않았습니다.

- BTC·ETH 각각 500 USDT × 5배로 산출된 **기존 연구 기록**: 144개 상태 중 진입 통과 0개; 지지를 받는 87개 모두 비용 반영 평균 순손익이 음수입니다.
- 후속 역사 구간의 실행 가능 가상 사건 23,565건 평균은 사건당 −7.36 USDT였습니다. 종목별 비중복 사건과 실제 위험 중단 후 거래 수는 별도 지표입니다.
- 이것은 400 USDT × 5배의 백테스트가 아닙니다. 기존 상태 모형의 크기 표본을 새 금액으로 바꾸어 표현하지 않습니다.

빈번 후보는 위험 중단 없이 고정 시간 후 청산하는 단순 신호 선별 결과입니다. 수수료·역사 펀딩 대용값을 반영했으나 손절, 청산 위험, 잔고 부족, 실제 체결과 주문 잔량, 위험 중단을 재생하지 않았습니다. 누적 가상 손실이 배정 원금을 넘으므로 해당 384/401건을 지속 가능한 실전 체결 횟수로 해석하면 안 됩니다. Binance USD-M OHLCV와 펀딩을 Bitget UTA의 대체 자료로 사용했습니다. 이전 연구에서도 기간을 살펴봤으므로 이후 역사 구간을 새 미사용 검증으로 부르지 않습니다.

재현 소스와 모든 그리드 결과는 같은 폴더의 `independent_15m_scan.py`, `independent_15m_results.json`, `independent_15m_all_candidates.csv`에 있습니다. 필요한 과거 NPZ 캐시는 용량 때문에 저장소에 포함하지 않았고, 결과 JSON의 SHA256으로 원자료를 대조할 수 있습니다. 원자료를 가진 환경에서는 `PROBABILITY_15M_CACHE=/절대경로/캐시 python3 independent_15m_scan.py`로 재실행합니다.

## 무엇이 통과를 뜻하는가

새 규칙을 먼저 고정한 다음 **새로 수집한 미래 자료**에만 적용합니다. 실제 잔고로 연속해서 실행 가능한 BTC·ETH 거래를 충분한 서로 다른 날짜에 모으고, 계정별 수수료·스프레드·슬리피지·펀딩을 반영한 손익 기대값의 날짜 단위 95% 신뢰 하한이 양수여야 합니다. 높은 거래 빈도와 비용 두 배 시나리오, 시간대·종목별 견고성, 서비스 재시작 및 미체결·부분체결도 별도로 확인합니다. 95% 하한은 미래 수익을 보장하지 않습니다. 수익이 난 상태가 하나 나오도록 기준을 낮추는 것은 통과가 아닙니다.
