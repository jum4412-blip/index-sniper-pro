승률보다 비용 포함 기대값을 봅니다

E = p × W − (1 − p) × L

p는 비용 포함 순손익이 양수일 확률, W는 양수였을 때의 평균 순이익, L은 음수였을 때 평균 순손실의 크기입니다. 수수료·스프레드·슬리피지·펀딩이 이미 순손익에 들어 있습니다. 만기 청산도 포함하기 때문에 목표가 2R라고 손익분기 승률을 단순히 1/3로 놓지 않습니다.

상태별 작은 표본의 승률을 그대로 믿지 않고, 같은 종목·사건·방향의 큰 그룹 쪽으로 베타-이항 축소 추정을 합니다. 종료한 훈련 사건만 사용하고 60분 간격을 비워 누수를 막습니다. 종목별 노출 중복을 줄이며, 서로 다른 날의 변동을 반영한 보수적 하한도 검사합니다. 이는 미래 수익 보증이나 완벽한 독립 표본 가정이 아닙니다.

설치와 실행

btc_eth_probability_v1.run은 기본 ~/btc_eth_probability_v1에 압축만 풉니다. 같은 설치 폴더가 이미 있으면 덮어쓰지 않고 중단합니다. 설치파일 실행으로 서비스·매매·텔레그램을 자동으로 시작하지 않습니다. EC2 Ubuntu의 본인 계정에서 Python 3.10 이상을 사용합니다. 전체 self-test는 포함한 오프라인 C++ 체결 시험을 빌드하므로 g++가 필요합니다. 처음 설치하거나 venv·g++가 없는 Ubuntu에서는 다음 패키지를 먼저 준비합니다.

sudo apt-get update
sudo apt-get install -y python3-venv build-essential
    
bash btc_eth_probability_v1.run
cd ~/btc_eth_probability_v1
./install_dependencies.sh
./prob self-test
./prob doctor-public

아래 파일의 값을 서버에서만 편집합니다. 텔레그램은 TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID 한 쌍을 사용합니다. 기존 .env를 재사용하려면 connection.json에 그 경로를 명시할 수 있습니다.

cp credentials.example.env credentials.env
chmod 600 credentials.env
nano credentials.env
cp connection.example.json connection.json

credentials.env의 키 이름은 BITGET_API_KEY, BITGET_SECRET_KEY, BITGET_PASSPHRASE, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID입니다. connection.json의 env는 ~/btc_eth_probability_v1/credentials.env 또는 기존 자격증명의 실제 경로로 지정합니다. legacy_root·trend_root·basic_root·psych_root·trail3_root는 이전 봇의 실제 위치를 확인해 적습니다. trail3_root의 기본값은 ~/eth_larry_trail3_500입니다.
