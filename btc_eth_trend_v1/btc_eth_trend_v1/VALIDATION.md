## 특히 확인한 동작

- 주문 의도 선저장, 응답 유실 시 재전송 금지, 재시작 뒤 미확정 주문 유지.
- IOC 부분 진입, 부분 청산의 잔량 계산과 소수점 주문 단위 보존.
- 단방향 reduce-only 청산, 양방향 기존 포지션 방향 청산, 이미 종료된 포지션에 반대 주문을 만들지 않음.
- 다른 주문의 체결/다른 포지션 이력을 자기 거래로 가져오지 않음.
- 최초 손절의 방향·가격·수량 확인, 분할 손절 수량 합산 시 주문 ID 중복 제외.
- 손절 확인 실패, 실제 체결 후 위험 초과 시 자기 포지션 청산 의도 저장 및 재시작 유지.
- 기존 일간/주간 손실 기준과 연속 손실 대기 유지. 최고 잔고 하락 한도는 날짜 변경으로 해제하지 않음.
- 수수료·펀딩비를 포함한 거래소 종료 이력의 정산 일치 검사. 불명확한 순손익을 0으로 바꾸지 않음.
- 미완료/미래 봉 제외, 봉 누락 차단, 가장 최근 완료 봉이 없는 경우 이전 방향으로 대체하지 않음.
- 손절을 불리하게 되돌리지 않고, 시장을 넘어서는 새 손절선은 청산 사유로 처리.
- 공개 전용 모드에서 비공개 조회와 주문 전송 금지. 출금·계좌 이체 엔드포인트는 구현/허용하지 않음.

실제 공개 API 점검으로 두 가지 데이터 문제를 확인하고 수정했습니다. 일봉은 관측된 UTC 16시 세션 경계를 따르며, 과거 봉 요청의 `endTime`에서 1ms를 빼면 페이지 사이에 하루가 빠질 수 있으므로 경계 시각 그대로 다음 요청에 사용합니다. 두 경우 모두 회귀 검사를 포함했습니다.

공개 사전 점검 당시 확인한 상품 단위:

| 종목 | 가격 단위 | 수량 단위 | 최소 수량 | 최소 주문 금액 | 공개 taker 요율 |
|---|---:|---:|---:|---:|---:|
| BTCUSDT | 0.1 | 0.0001 BTC | 0.0001 BTC | 5 USDT | 0.0006 |
| ETHUSDT | 0.01 | 0.01 ETH | 0.01 ETH | 5 USDT | 0.0006 |

이 표의 값은 설명용 스냅샷입니다. 실주문 시 상품 단위를 다시 조회하며 하드코딩된 이 표를 사용하지 않습니다.

## 아직 검증하지 않은 부분

- 사용자의 실제 UTA 계좌 조회, 레버리지 변경, 실주문 체결 및 거래소 손절 생성/목록 응답. 기존 서버에서 `setup`과 실행 후 점검이 필요합니다.
- 실제 사용자의 호가 체결 지연, 수수료 등급, 급변장 슬리피지, 비공개 API 제한과 장애 복구의 모든 경우.
- 사용자의 EC2 systemd 설치/재부팅 실험. 설치 스크립트를 제공하지만 원격 서버에 접속하거나 배포하지 않았습니다.
- 장기 백테스트, 기간을 분리한 독립 검증, 여러 시장 국면의 비용 후 양의 기대값. 전략의 수익성을 입증하지 않았습니다.
- 서버 중단 중의 로컬 추세 손절 실행. 최초 거래소 손절만 남으며, 자동 재시작은 무중단 보장을 뜻하지 않습니다.
- 현금 입출금 조정, 다른 담보·수동 거래·다른 봇을 포함한 공동 계좌 운용, 휴대전화 알림과 외부 장애 감시.

업로드된 SSH 개인키를 읽거나 사용하지 않았고, 비공개 거래소 자격 증명으로 접속하거나 실제 금융 거래를 수행하지 않았습니다. 테스트 통과는 원금 보장, 수익 보장, 운영 결함 부재에 대한 인증이 아닙니다.
